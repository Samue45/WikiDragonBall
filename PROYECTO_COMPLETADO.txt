📡 ENDPOINTS API REST
═══════════════════════════════════════════════════════════════════════════════

AUTENTICACIÓN
────────────────────────────────────────────────────────────────────────────
POST   /api/auth/register          Registrar usuario
POST   /api/auth/login             Iniciar sesión


PERSONAJES
────────────────────────────────────────────────────────────────────────────
GET    /api/characters             Listar (paginado)
GET    /api/characters/:id         Detalle
GET    /api/characters/planets/list Listar planetas


FAVORITOS (requiere JWT)
────────────────────────────────────────────────────────────────────────────
POST   /api/favorites              Añadir a favoritos
GET    /api/favorites              Mis favoritos
DELETE /api/favorites/:characterId Eliminar de favoritos


COMENTARIOS
────────────────────────────────────────────────────────────────────────────
POST   /api/comments               Crear (requiere JWT)
GET    /api/comments/:characterId  Listar por personaje
PUT    /api/comments/:id           Editar propio (requiere JWT)
DELETE /api/comments/:id           Eliminar propio (requiere JWT)


USUARIO
────────────────────────────────────────────────────────────────────────────
GET    /api/users/me/stats         Mis estadísticas (requiere JWT)


ADMIN (requiere JWT + role admin)
────────────────────────────────────────────────────────────────────────────
GET    /api/admin/users            Listar usuarios
GET    /api/admin/comments         Listar todos comentarios
DELETE /api/admin/comments/:id     Eliminar comentario
GET    /api/admin/stats            Estadísticas globales
